## 支持哪些音频格式？

常见格式均可播放：MP3、FLAC、WAV、OGG、AAC、APE 等。无损与高规格本地文件走原生输出通道，在线与普通 MP3 走内置解码。

## 关闭窗口后音乐还在放，怎么彻底退出？

这是「最小化到托盘」的默认行为：点关闭按钮会把窗口收到系统托盘，音乐继续播放。如果想点关闭就直接退出：

1. 打开「设置 → 播放」
2. 关闭「关闭窗口时最小化到托盘」

此后点关闭按钮即彻底退出。开启该选项时，也可以右键托盘图标选择「退出」。

## 如何检查更新？

打开「设置 → 更新」，点击「刷新检测」。检测结果来自 GitHub Releases，有缓存机制，不会频繁请求。桌面端与 Android 端的版本线相互独立，不会串版本。

## 网易云登录安全吗？

登录态仅保存在本机，凭据不会上传到任何第三方服务器。若遇到风控提示，建议改用验证码登录。

## 数据存在哪里？

曲库索引、播放统计与设置都保存在本机应用数据目录（SQLite），卸载应用不会自动删除你的音乐文件。具体路径可在「设置 → 其他」中查看。
