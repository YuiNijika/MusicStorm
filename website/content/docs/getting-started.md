## 下载与安装

前往首页的[下载区](#download)获取最新版本，或在 [GitHub Releases](https://github.com/YuiNijika/MusicStorm/releases) 中选择对应平台的安装包。

| 平台 | 状态 |
| --- | --- |
| Windows | 已发布 |
| macOS | 即将推出 |
| Android | 即将推出 |

Windows 版为 NSIS 安装包，双击后按提示完成安装即可，无需管理员权限。

## 播放第一首歌

MusicStorm 把**本地曲库**和**云端音乐**合在一起：

- 想听本地文件：在侧边栏点「新建」→ 导入文件夹或文件，扫描完成后即可播放
- 想听网易云：在设置中登录账号，歌单会出现在「云端」分区

## 全屏播放

点击底部播放条的封面，进入全屏播放器。全屏模式下可以：

1. 切换三种播放模板：经典、封面、纯歌词
2. 调整歌词对齐方式
3. 双击顶部空白处最大化或还原窗口

按 `Esc` 或点左上角「收起」退出全屏。
